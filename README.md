# 📚 Study Management System

A console-based Study Management System built with Python to help students organize their academic work efficiently.

The application allows users to register, log in, manage subjects, create study tasks, track their progress, and save all their data using JSON files.

---

## ✨ Features

- 🔐 User Registration & Login
- 📚 Subject Management
- ✅ Task Management
- 📈 Progress Tracking
- 💾 Automatic JSON Data Storage
- 👥 Multi-user Support
- ⚠️ Input Validation & Error Handling
- 📊 Subject-wise Progress Statistics

## 🚀 Getting Started

### Clone the repository

```
git clone https://github.com/swetarkshukla/Study-Management-System.git
```

### Move into the project folder

```
cd Study-Management-System
```

### Run the application

```
python main.py
```
